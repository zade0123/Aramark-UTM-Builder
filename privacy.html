Privacy Policy

Aramark UTM Builder — Chrome Extension

Effective: March 23, 2026 Last Updated: April 13, 2026 Contact: dohan-zade@aramark.com Internal Tool — Aramark Only
01 — Overview

About This Extension

The Aramark UTM Builder is a Chrome Extension developed and maintained by the Aramark Digital Analytics team. It is an internal productivity tool that helps Aramark employees build standardized UTM-tagged URLs for marketing campaign tracking.

This privacy policy describes what information is collected when you use the extension, how that information is used, and your rights with respect to your data. By installing or using this extension, you agree to the practices described in this policy.

Internal use only. This extension is distributed privately to Aramark employees and is not available to the general public. All data collected stays within Aramark-controlled systems.
02 — Permissions Used

Chrome Permissions

This extension requests the following Chrome permissions. Each is used solely for the features described below and for no other purpose.

Permission Why It's Needed
sidePanel Displays the UTM Builder interface in Chrome's side panel.
tabs Reads the URL of the currently active tab when you click "grab current page," so it can auto-fill the Base URL field. No tab data is stored or transmitted.
storage Stores a randomly generated anonymous client ID in local browser storage. This ID contains no personal information and is used only for anonymous usage analytics.
contextMenus Adds an "Open UTM Builder" item to the right-click context menu for quick access.
Host: script.google.com Communicates with the Aramark Google Apps Script backend to save UTM entries and retrieve shared dropdown values. No data is sent to any non-Aramark endpoint through this permission.
Host: google-analytics.com Sends anonymous usage events to Google Analytics 4 via the Measurement Protocol. See Section 4 for details.
03 — Data Collected

What We Collect

We collect only the minimum data necessary to operate the tool and understand overall usage. We do not collect any automatically inferred personal data, track your browsing history, or access any content outside of the specific interactions described below.

  • UTM Form Data — When you save a UTM link, the following fields are written to a private Aramark-controlled Google Sheet: destination URL, UTM campaign parameters (source, medium, campaign, content, term), Author Name (as entered by you), Line of Business, and Use Description. This data is used solely for internal campaign taxonomy governance and is accessible only to the Digital Analytics team.
  • Author Name & Line of Business — Included in anonymous usage events sent to Google Analytics 4 (see Section 4) to understand adoption across teams. This is the same value you type into the form — no identity resolution or cross-referencing is performed.
  • Anonymous Client ID — A randomly generated identifier (UUID) stored in your browser's local storage. It does not contain your name, email, Aramark ID, or any other identifying information. It is used only to de-duplicate GA4 events across sessions.
  • Current Tab URL — Read momentarily when you click the "grab current page" button to auto-fill the Base URL input. This URL is never stored, logged, or transmitted anywhere.
We never collect: your Aramark login credentials, email address, full name, IP address, device identifiers, browsing history, or any data from pages you visit outside of the explicit "grab current page" action.
04 — Analytics

Google Analytics 4 Usage

This extension uses Google Analytics 4 (GA4) via the Measurement Protocol to collect anonymous, aggregated usage statistics. Events are sent directly from the extension to Google's servers using a server-side API secret — no GA4 JavaScript library is loaded or injected into any webpage you visit.

The following events are tracked:

Event When It Fires Data Sent
page_view When the side panel is opened. Anonymous client ID only.
utm_saved When a UTM link is successfully saved. Author Name, Line of Business, anonymous client ID.
url_copied_from_history When a URL is copied from the history tab. Anonymous client ID only.
vanity_url_created When a Bitly vanity URL is successfully generated alongside a saved UTM link. Author Name, Line of Business, anonymous client ID.

GA4 data is processed by Google LLC in accordance with Google's Privacy Policy. Analytics data is used exclusively by the Aramark Digital Analytics team to improve the extension. No GA4 data is shared with any third party beyond Google as the analytics processor.

05 — Data Sharing

How We Share Data

We do not sell, rent, or trade your data. Data collected by this extension is used solely for internal Aramark purposes.

Data is shared only as follows:

  • Google LLC (Analytics Processor) — Anonymous usage events are transmitted to Google Analytics 4. Google acts as a data processor under the terms of their Data Processing Agreement with Aramark.
  • Aramark Digital Analytics Team — UTM entries saved to the Google Sheet are accessible only to authorized members of the Digital Analytics team within Aramark's Google Workspace environment.

No data is shared with any other third parties, advertisers, data brokers, or external organizations.

06 — Data Retention

How Long We Keep Data

  • UTM Entries (Google Sheet) — Retained indefinitely for taxonomy governance and historical reporting. Entries may be deleted upon request.
  • GA4 Analytics Events — Retained for 14 months per GA4's default data retention setting, after which they are automatically deleted by Google.
  • Anonymous Client ID (browser storage) — Stored locally in your browser until the extension is uninstalled or browser storage is cleared. This data never leaves your device except as associated with GA4 events.
07 — Security

Data Security

All data transmissions from this extension use HTTPS. The backend Google Apps Script endpoint is access-controlled within Google's infrastructure. The GA4 Measurement Protocol API secret is embedded in the extension but does not grant access to any personally identifiable data — it is a write-only telemetry credential.

The Google Sheet storing UTM entries is accessible only to authorized Aramark personnel via Google Workspace permissions. No public-facing access is provided.

08 — Your Rights

Your Rights & Choices

  • Access & Deletion — You may request access to or deletion of any UTM entries associated with your Author Name by contacting the Digital Analytics team at dohan-zade@aramark.com.
  • Uninstall — Uninstalling the extension immediately stops all data collection. Your local anonymous client ID is removed when browser storage is cleared.
  • Analytics Opt-out — As this is an internal tool, analytics cannot be disabled individually; however, you may contact the Digital Analytics team to discuss your concerns.
